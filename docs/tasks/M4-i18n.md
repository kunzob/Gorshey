# M4 — i18n (bo / en, extensible)

**Goal:** locale detection, switching, string lookup, metadata picking, and time formatting — extensible to fr / zh-Hans by adding files only.
**Skills:** `gorshey-tibetan`.

## Files
`src/i18n/i18n.ts`, `src/i18n/locales.ts`, `src/i18n/catalogs/en.json`, `src/i18n/catalogs/bo.json`, `tests/i18n.test.ts`

## Functions
- `LOCALES = [{ code: 'bo', label: 'བོད་ཡིག' }, { code: 'en', label: 'English' }] as const` — the only list to edit when adding a language.
- `detectLocale(): Locale` — `localStorage('gorshey.locale')` → first match in `navigator.languages` (prefix match) → `'en'`.
- `setLocale(l)` — sets `document.documentElement.lang` **via a callback provided by ui/** (i18n must not touch the DOM), persists, emits `locale`.
- `t(key, vars?)` — lookup with `{n}` interpolation and `Intl.PluralRules` (fallback to `en` rules when `bo` unsupported); missing key → English → the key itself, with a dev-mode console warning.
- `pick(map, locale)` — `map[locale] ?? map.en ?? map.bo ?? ''`.
- `formatClock(date)`, `formatDuration(sec)` — `Intl.DateTimeFormat` with `numberingSystem: 'latn'`; for `bo` use `en` formatting.
